# RotaCerta Backend

API REST da plataforma RotaCerta desenvolvida com Java 21 e Spring Boot.

## Stack
- Java 21
- Spring Boot 3.5.5
- Spring Web
- Spring Data JPA
- Spring Validation
- Spring Transaction Management
- PostgreSQL
- Flyway
- Swagger/OpenAPI
- Spring Boot Actuator
- Maven
- Docker

## Desenvolvimento
```bash
mvn spring-boot:run
```

## Endpoints úteis
- `GET /api/dashboard`
- `GET /api/orders`
- `GET /api/tracking/{trackingCode}`
- `GET /actuator/health`
- `/swagger-ui.html`
