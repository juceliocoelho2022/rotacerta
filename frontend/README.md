# RotaCerta Frontend

Painel web operacional desenvolvido com React, TypeScript e Vite.

## Stack
- React 19
- TypeScript
- Vite
- React Router
- Axios
- Lucide React
- Nginx
- Docker

## Desenvolvimento
```bash
npm install
npm run dev
```

Por padrão, o frontend consome a API em `http://localhost:8080`.
